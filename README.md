# 🚀 Personal Portfolio Website — Saswat Sahay

A modern, responsive, and visually polished personal portfolio website built using **HTML**, **CSS**, and **GrapesJS**.  
This website showcases my skills, services, portfolio work, testimonials, and contact information through a sleek, dark-themed UI enhanced with animations and interactive design elements.

---

## 🖥️ Live Features

### 🌟 **Modern UI/UX**
- Dark theme with accent color **#FD7041**
- Smooth transitions and hover animations
- Sticky, responsive navigation bar

### 📱 **Fully Responsive Design**
- Mobile-first layout  
- Adaptive grid for portfolio, services & testimonials  
- Navigation collapses into a mobile menu at smaller screens

### 🧩 **Sections Included**
#### **1. Hero Section**
- Dynamic headline  
- Call-to-action button  
- Radial gradient background overlay  

#### **2. About Section**
- Personal introduction + profile image  
- Two CTA buttons: *Download CV* & *Contact*  

#### **3. Skills / Services**
Six feature/service cards including:
- UI/UX  
- Machine Learning  
- Web Development  
- Data Science  
and more — each with icons, hover effects, and descriptions  

#### **4. Statistics**
Counters for:
- Projects Completed  
- UI Concepts  
- Happy Clients  
- Hours Spent  

#### **5. Portfolio Section**
Showcases six projects with:
- Hover zoom effect  
- Color overlay  
- Title & short description  

#### **6. Testimonials**
Three testimonial cards containing:
- Profile photos  
- Feedback text  
- Name and role labels  

#### **7. Contact Section**
Includes:
- Contact form (Name, Email, Subject, Message)
- Address  
- Email  
- Phone number  

#### **8. Footer**
Social media links + copyright text
